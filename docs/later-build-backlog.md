# IV Outreach: later-build backlog

Updated November 12, 2026. This is a planning list, not authorization to buy services or activate accounts. The first growth build is described in [growth-build.md](growth-build.md); source research and prices are in [integration-research-2026-11-12.md](integration-research-2026-11-12.md).

| Priority | Candidate | Intended benefit | What should trigger the build |
| --- | --- | --- | --- |
| Next | Curated Apify Actors | Specialist directories, reviews and industry-specific research | A measured discovery gap; review each Actor's output, commercial terms and maximum run cost. |
| Next | Crawlee | Larger, more resilient own-site crawls | The bounded three-page reader proves insufficient. The current build reuses the existing guarded fetcher with Readability, keeping installation small. |
| Next | Scheduled watchlists / changedetection.io | Automatic change alerts | Users need monitoring beyond Check now. Choose explicit opt-in scheduling and explain that local checks require an awake computer; continuous hosting is separate. |
| Next | Direct Studio / Signal brief import contract | One-click structured creative handoff | Both receiving apps implement an authenticated, versioned import endpoint or file association. Today Outreach copies/exports a brief and can open the installed apps; it does not submit work automatically. |
| Later | Google Places API | Live photos and business details | Profile quality warrants the cost and attribution/storage implementation. Preserve the free own-site image preview. |
| Later | Hunter | Backup contact discovery | A benchmark shows BetterContact misses enough suitable contacts to justify another supplier. |
| Later | Activepieces Community Edition | CRM, spreadsheet and booking workflow connectors | Real customer workflow requests; keep the MIT community components separate from commercial enterprise features. |
| Later | YouTube Data API | Public channel/topic research and creator collaborations | Creator use cases become a priority; implement quota accounting and source links. |
| Signal roadmap | Ayrshare | Authorized social scheduling and analytics | IV Signal needs broader publishing coverage and paid per-brand pricing is viable. Separate ongoing social costs from one-off Outreach search credits. |
| Research | webanalyze | CMS and technology observations | Verify the technology-definition dataset license and accuracy separately from the MIT engine. |
| Hold | Postiz / Firecrawl or other copyleft stacks | Social or crawling capabilities | A concrete missing capability plus a reviewed licensing plan. No copying into the closed app merely to remove a product name. |
| Hold | Brave Search API | Alternative search provider | Written clarification of permitted multi-customer use and its listed multi-level-marketing restriction for this audience. |

Product improvements worth prioritizing after real usage: industry presets for Hollis, realtors, insurance and opt-in relationship marketing; campaign-level results reporting; provider freshness and duplicate benchmarks; paginated mailbox sync beyond the bounded recent-reply window; direct watched-page change diffs; lead search/filtering in the opportunity picker; and a production account/credit gateway. Current private local Stripe testing is not a public multi-tenant billing service.

No automated cold social messages, fabricated identities, email guessing or suppression bypasses are part of this backlog.
